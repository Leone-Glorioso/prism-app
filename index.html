About LeoTeX

LeoTeX . An online LaTeX editor that keeps your projects in your own private GitHub repository and compiles them with a complete TeX Live in GitHub Actions.

  • Free software under the MIT licence. Source: github.com/prism-latex/prism-app.
  • No analytics and no third-party scripts. The page talks to GitHub (and, only if you use an account, to the account service) and nothing else.
  • Security notes: SECURITY.md.

    Write LaTeX anywhere.
    Your files stay yours.
    
          
    LeoTeX is an online editor with a complete TeX Live behind it. Edit in the browser, compile any document and read the PDF next to your source.
    
          
      
            
    • Projects live in your own private GitHub repository, with full history.

    Connect your projects repository
    
    
    Your files live in a private GitHub repository that you own. Each person uses their own repository.
    
    
    
      
      
      
      
      
    
    
    
    If you enter the expiry date you chose on GitHub, the app reminds you 10 days before it ends (GitHub also emails you).
    
    
    
      Keep the token in this browser
      
      
      
    
    
    
    
    
      First time? Create your own repository
      
      
        
    1. Create a private repository on GitHub (for example prism-data) and tick Add a README file:
          github.com/new
      2. 
        
    2. Create a token: GitHub → Settings → Fine-grained tokens. Repository access: only that repository. Permissions: Contents, Actions and (for the first setup only) Workflows — all read and write.
      3. 
        
    3. Enter owner, repository and token here and press Connect. The app offers to set the repository up. Afterwards you can remove the Workflows permission from the token.
      4. 
      
    
      
    To share one repository, give each person their own: GitHub does not let fine-grained tokens use another person's personal repository.

    Good to know
    
        
      
          
    • Nothing reaches GitHub until you press Save. Unsaved text is kept in this browser.
      • 
          
    • The compiler is a complete TeX Live in GitHub Actions. Choose its version under Compiler on the start screen.
      • 
          
    • If two people (or Codex or Claude) edit the same file, the app asks which version to keep.
      • 
          
    • Your token stays in this browser, or sealed with your own passphrase in your account. Use Connection and security to change or clear it.

    Set up this repository
    
    
    
    
    This commits the compile workflow (.github/workflows/compile.yml, .github/scripts/compile.sh) and a project list. GitHub only accepts workflow files from a token that has the Workflows: read and write permission — add it to your token for this step, and remove it again afterwards. Nothing else is changed.
